# Sistema de diseño base

## Objetivo visual

Transmitir confianza, claridad, cercanía y orden.

## Principios

- Interfaz limpia.
- Jerarquía visual evidente.
- Textos cortos.
- Formularios simples.
- Uso moderado de iconografía.
- No saturar con elementos médicos estereotípicos.
- Evitar lenguaje visual alarmista.

## Tokens mínimos

Definir variables para:

- color-brand-primary
- color-brand-secondary
- color-surface
- color-text
- color-muted
- color-success
- color-warning
- color-error
- radius-sm
- radius-md
- radius-lg
- shadow-sm
- shadow-md
- spacing-1 a spacing-12

## Tipografía

Debe existir una jerarquía consistente para:

- Display.
- H1.
- H2.
- H3.
- Body.
- Small.
- Label.

## Componentes mínimos

- Button.
- Input.
- Textarea.
- Select.
- Checkbox.
- Alert.
- Card.
- Badge.
- Header.
- Footer.
- Modal, solo si resulta necesario.
- Toast o confirmación accesible.

## Estados

Cada componente interactivo debe contemplar:

- default
- hover
- focus
- active
- disabled
- error
- loading, cuando aplique

## Responsive

Puntos de referencia sugeridos:

- móvil: 320–767 px
- tablet: 768–1023 px
- escritorio: 1024 px en adelante

No diseñar solo para escritorio.

# Agente operativo del proyecto

## Propósito

Salvación M dispone de un agente dedicado a revisar, corregir y validar el proyecto de manera continua.

## Archivo principal

`.github/agents/salvacion-m-agent.md`

## Responsabilidades

- Control de cumplimiento de requisitos.
- Revisión de sprints.
- Detección de desviaciones.
- Corrección de incumplimientos.
- Validación técnica.
- Mantenimiento de memoria.
- Control de calidad.
- Seguimiento de riesgos.

## Regla clave

El agente no puede considerar una tarea cumplida por mera existencia de código o documentación. Debe existir evidencia funcional y validación.

## Relación con la memoria

Toda intervención relevante debe quedar reflejada en:

`docs/08-memoria-del-sistema.md`

## Relación con criterios de aceptación

Debe contrastar siempre con:

`docs/09-criterios-de-aceptacion.md`

`docs/07-roadmap.md`

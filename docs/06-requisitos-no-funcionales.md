# Requisitos no funcionales

## Accesibilidad

Objetivo: aproximarse a WCAG 2.2 AA.

- Navegación por teclado.
- Contraste suficiente.
- Focus visible.
- Labels asociados.
- Mensajes de error claros.
- Semántica HTML.
- Texto alternativo.
- Targets táctiles adecuados.

## Rendimiento

- Optimización de imágenes.
- Lazy loading.
- Minimización de JS.
- Caché.
- Core Web Vitals.

## SEO

- Metadatos.
- Open Graph.
- Sitemap.
- Robots.
- Schema.org cuando corresponda.
- URLs limpias.

## Seguridad

- HTTPS.
- CSP.
- HSTS.
- Cookies seguras.
- Protección CSRF cuando aplique.
- Sanitización y validación.
- Rate limiting.
- Gestión segura de secretos.
- Dependencias actualizadas.

## Observabilidad

- Logs estructurados.
- Registro de errores.
- Auditoría del CRM.
- Métricas básicas.

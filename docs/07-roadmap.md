# Roadmap

## Fase 1 — Base del producto

- Identidad de marca.
- Arquitectura de información.
- Diseño UI/UX.
- Sitio público.
- Formulario.
- Backend.
- Base de datos.
- CRM independiente.
- Integración formulario -> CRM.

## Fase 2 — Cumplimiento y calidad

- Privacidad.
- Términos.
- Accesibilidad.
- SEO.
- Seguridad.
- Auditoría UX/UI.
- Pruebas.

## Fase 3 — Gestión avanzada

- Roles.
- Asignación de responsables.
- Historial.
- Filtros.
- Exportaciones.
- Recordatorios.
- Dashboard.
- Métricas.

## Fase 4 — Automatización

- Plantillas.
- Notificaciones.
- Clasificación asistida.
- Automatización de seguimiento.
- Integraciones.

## Criterio de cierre de sprint

Un sprint solo se considera terminado cuando:

- Requisitos implementados.
- Pruebas ejecutadas.
- Errores críticos cerrados.
- Documentación actualizada.
- Memoria del sistema actualizada.
- Criterios de aceptación verificados.
